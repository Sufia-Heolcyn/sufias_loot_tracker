# Sufia's Loot Tracker (PF2e Party Treasure by Level)

A Foundry VTT (v12 / v13) module for the **Pathfinder Second Edition (`pf2e`)** system that automates and tracks **Table 10-9: Party Treasure by Level** from the *Pathfinder GM Core* rulebook across Levels 1–20.

## Installation via Manifest URL

In Foundry VTT **Add-on Modules -> Install Module**, paste this **Manifest URL** at the bottom of the dialog:

```text
https://raw.githubusercontent.com/Sufia-Heolcyn/sufias_loot_tracker/main/module.json
```
