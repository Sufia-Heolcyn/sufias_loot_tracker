# Sufia's Loot Tracker (v1.0.1)

A Foundry VTT (v13 / v14) module for the **Pathfinder Second Edition (`pf2e`)** system that automates and tracks **Table 10-9: Party Treasure by Level** from the *Pathfinder GM Core* rulebook across Levels 1–20.

## Installation via Manifest URL

In Foundry VTT **Add-on Modules -> Install Module**, paste this **Manifest URL** at the bottom of the dialog:

```text
https://github.com/Sufia-Heolcyn/sufias_loot_tracker/releases/latest/download/module.json
```

## How to Open in Game (GM Only)

1. In the left-hand **Scene Controls** bar on the canvas, click **Journal Notes** (map pin icon).
2. Click the **Party Treasure by Level** button (coin stack icon).
3. You can also open it from the header bar of the PF2e **Party** actor sheet.
